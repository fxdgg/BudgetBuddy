## 2. 用户选择机制（budget setup autorun）

- [x] 2.1 【coder-senior | cross_module】新增 `core/lib/autorun.py`（Python stdlib only，argparse 子命令 `list`/`on`/`off`/`apply`）：状态文件 `~/.budgetbuddy/auto-run.json`（`{"agents": [...]}` 排序、indent 2、sort_keys）；行级补丁复刻 `model_resolver.py` `rewrite_agent_file` 算法（on=插入/改值、off=删行、锚点=name/description 最后出现行之后、行尾保留、临时文件原子写、仅触碰一行）；`apply`=全量对齐（清单内 on/清单外 off）；**种子化口径：状态缺失时 on/off 先扫描已安装 agent，仅「`enabledAutoRun` 行存在且值解析为 `true`」进基线（`false` 行视为用户显式关闭，不翻转）**；**作用域：on/off 补丁落当前探测到的安装态（`BUDGET_PLATFORM_KIND`/`BUDGET_AGENTS_DIR` 环境变量），多项目级安装需逐项目执行**；**unknown 形态（五级探测未命中）on/off/apply 非零退出并提示先安装或 `BUDGET_PLATFORM=` 显式指定**；**`list` 双栏输出（全局状态清单 + 当前安装态实况逐 agent 比对）；`list` 遇状态文件损坏时状态栏明示损坏与修复路径、退出码 0、不改写文件（只读）**；**on/off/apply 遇状态文件 JSON 损坏非零退出并提示修复，绝不覆盖写**；**`on` 输出安全知情提示（明示免审批语义 + 列出该 agent 将免审批的 bash 模式，`*`/git 类醒目）——bash 模式从 `<BUDGET_AGENTS_DIR>/.bash-patterns.json` 读取目标 agent 的 `bash_allow`（design D7），文件缺失（旧安装）时降级为通用知情提示（不列具体模式）且不阻断开启，`bash_allow` 为 `[]` 时提示无 bash 权限**；未知名非零退出并列可用名（已安装 agents 目录 .md 主名）；非 codebuddy 平台 on/off/apply 输出平台替代指引（opencode：permission map/会话 always/`--auto`；claudecode：settings.json permissions/权限模式）并 exit 0 零文件修改；`list` 只读任何平台可用
- [x] 2.2 【coder-standard | test_only】新增 `tests/test_autorun.py`：复刻 `tests/test_preset.py` `RewriteUnitTests(SandboxTestCase)` 沙盒模式（tmp 目录伪造 agents 目录 + 隔离 HOME + 子进程直调 `core/lib/autorun.py`，先例 L103-106/L195-209），将原沙盒手动验证项转为自动化用例：① 补丁插入/改值/删除与锚点（name/description 最后出现行之后）；② CRLF 行尾保留；③ 幂等（重复 on/off 字节稳定）；④ 种子化仅值 `true` 进基线（`enabledAutoRun: false` 行不被翻转）；⑤ apply 全量对齐（清单内 on/清单外 off）；⑥ 损坏 JSON 非零退出且状态文件字节不变；⑦ unknown 形态 on/off 非零退出、list exit 0；⑧ opencode/claudecode 降级 exit 0 零文件修改（mtime/内容双核验）；⑨ list 双栏输出解析；⑩ list 遇损坏状态文件只读展示（状态栏明示损坏 + 修复路径、退出码 0、状态文件字节不变）；⑪ `on` 输出 bash 模式取自 `.bash-patterns.json`（存在时列目标 agent 模式；缺失时降级通用提示且开启照常完成）
